# 🧠 Natural Language Processing – Sentence Classification
This project focuses on sentence classification using neural network architectures. We explore and compare the performance of different models in classifying sentences into their respective categories using word embeddings as input features.

# 🔍 Project Overview
In this project, we:

Preprocessed and vectorized text using word embeddings.

Designed and trained various neural network models:

✅ Feedforward Neural Network (FNN)

✅ Long Short-Term Memory (LSTM)

🚧 Transformer model (not included in code, explored in presentation)

Analyzed performance and hyperparameters through a PowerPoint presentation summarizing the results and insights.

# 📁 Files Included
NLP_Q2_LSTM.ipynb: Jupyter Notebook containing implementation and training of the Feedforward Neural Network and LSTM models.

Sentence_Classification_Presentation.pptx (Assumed): Slide deck summarizing model performance and findings.

# ⚙️ Requirements
Make sure the following Python packages are installed before running the notebook:

``` bash
numpy
pandas
matplotlib
scikit-learn
nltk
tensorflow
keras
```

To install all at once:

```bash
pip install numpy pandas matplotlib scikit-learn nltk tensorflow keras
```

# 🚀 How to Run
Clone the repository or download the files.

Launch Jupyter Notebook:

```bash
jupyter notebook
Open NLP_Q2_LSTM.ipynb.
```

Follow the notebook and run the cells sequentially.
